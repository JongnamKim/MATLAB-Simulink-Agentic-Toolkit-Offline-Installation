Air-Gapped Installation Guide

MATLAB/Simulink Agentic Toolkit폐쇄망 설치 및 검증 가이드

외부망 파일 준비부터 폐쇄망 설치, MATLAB 세션 연결과 검증까지 순서대로 안내합니다.

전체 흐름

외부망 PC에서 agentic-offline.zip과 AgenticToolkitOfflineInstallerApp.m을 내려받습니다. 압축 해제 폴더와 함께 App 파일을 폐쇄망 PC로 반입한 뒤, Installer App으로 설치를 자동화합니다.

외부망에서 Files and App 다운로드

Agentic Toolkit Files and App 다운로드 페이지에서 agentic-offline.zip과 AgenticToolkitOfflineInstallerApp.m을 내려받고 ZIP 파일의 압축을 해제합니다. 해제된 폴더에는 MCP binary, MCP Toolbox와 MATLAB/Simulink Agentic Toolkit 등이 포함됩니다.

폐쇄망으로 반입

압축을 해제한 agentic-offline 폴더(예: D:\agentic-offline)와 함께 AgenticToolkitOfflineInstallerApp.m 파일을 폐쇄망 PC로 반입합니다. SHA-256 해시와 승인 기록을 보관합니다.

App에서 설치 및 검증

Installer App에서 Validate Files, Install Offline, Install Skills, Status / Initialize 순서로 확인합니다.

환경 선택

대상 OS를 선택하면 참고용 수동 설치 명령과 binary 이름이 자동으로 바뀝니다. 에이전트는 Roo Code 설정 예시로 고정되어 있습니다.

다운로드 및 반입 파일

외부망 PC에서 두 파일을 다운로드하고 agentic-offline.zip의 압축을 해제한 뒤, 해제 폴더의 구성 항목과 함께 반입할 App 파일을 확인합니다.

자동 설치

          
폐쇄망 PC에서 압축 해제 폴더와 함께 반입한 AgenticToolkitOfflineInstallerApp.m 파일이 있는 폴더를 MATLAB의 현재 폴더로 지정하고 Installer App을 실행합니다. App의 Offline Package Folder에는 압축을 해제한 agentic-offline 폴더를 지정한 뒤 파일 검증, 오프라인 설치, 스킬 설치, 초기화를 순서대로 수행합니다.

        

        

          
          
        

        

          
폐쇄망 PC: Installer App 실행

          

        

        

          

            
1
Installer App 실행 화면

            
위 명령으로 AgenticToolkitOfflineInstallerApp을 실행하면 아래 화면이 나타납니다. 압축을 해제한 agentic-offline 폴더와 함께 반입한 App 파일을 사용합니다.

            
          


          

            
2
설치 단계

            
진행 순서
폴더 지정 → Toolkit 선택 → Install Offline → Skill Groups 선택 → Install Skills → Status / Initialize

            

              

                
① Offline Package Folder — 설치 파일 위치 지정

                
Browse를 눌러 MCP 파일과 Toolkit 폴더가 들어 있는 압축 해제 폴더(예: D:\agentic-offline)를 선택합니다. 이 값은 환경 선택의 반입 루트 폴더와 일치해야 합니다.

              

              

                
② Agentic Toolkit — 설치 대상 선택 및 설치

                
MATLAB, Simulink, MATLAB and Simulink 중 하나를 선택합니다. 기본 선택은 MATLAB and Simulink입니다. 선택을 마친 뒤 Install Offline을 누릅니다.

                
App은 선택한 Toolkit에 맞춰 setupAgenticToolkit("install", Offline=true, Prompt=false)를 실행합니다. 하단 로그에서 오류 없이 설치가 완료되었는지 확인합니다.

              

              

                
③ Install Skills — 사용할 Skill Groups 선택

                
선택한 Toolkit의 파일에서 읽어 온 MATLAB Skill Groups와 Simulink Skill Groups를 확인합니다. 사용할 그룹을 선택하고 Selected Skill Groups에서 선택 내용을 확인한 뒤 Install Skills를 누릅니다.

                
Windows에서는 각 스킬 폴더의 링크가 %USERPROFILE%\.agents\skills 아래에 생성됩니다. 이미 같은 이름의 폴더나 링크가 있으면 App 로그에 표시하고 건너뜁니다.

              

              

                
④ Status / Initialize — 설치 상태 확인 및 세션 초기화

                
MATLAB MCP Server와 Toolkit의 설치 상태를 확인하고 Toolkit 폴더를 MATLAB 경로에 추가합니다. 현재 MATLAB 세션을 MCP에서 사용할 수 있도록 초기화한 뒤 하단 로그에서 결과를 확인합니다.

              

            

          


          

            
3
MATLAB 세션 연결 자동화

            
현재 실행 중인 MATLAB을 MCP Server에서 사용하려면 해당 세션을 공유해야 합니다. startup.m에 설치한 Toolkit에 맞는 코드를 추가하면 MATLAB을 시작할 때 세션 공유가 준비됩니다. 아래 두 예시 중 설치 유형에 맞는 하나를 추가합니다.


            

            
기존 startup.m 확인

            
MATLAB Command Window에서 다음 명령을 실행합니다. 파일이 여러 개 표시되면 첫 번째 파일을 편집합니다. MATLAB은 경로에서 먼저 찾은 startup.m을 실행합니다.

            

              
startup.m 위치 확인

              
which('startup', '-all')

            


            
startup.m이 없으면 생성

            
다음 명령으로 userpath 아래에 새 파일을 만듭니다. 기존 파일이 있다면 원래 내용을 유지하고 초기화 코드만 추가합니다.

            

              
startup.m 생성 또는 편집

              
edit(fullfile(userpath, 'startup.m'))

            

            
userpath에 여러 폴더가 지정되어 명령이 실패하면 userpath를 실행하여 첫 번째 폴더를 확인하고, edit(fullfile('<첫 번째 폴더의 실제 경로>', 'startup.m'))처럼 경로를 직접 지정합니다.


            
A. MATLAB Agentic Toolkit만 사용하는 경우

            
MATLAB Toolkit의 공식 README는 shareMATLABSession()을 startup.m에 추가하도록 안내합니다. 이 명령은 현재 MATLAB 세션을 MCP Server가 연결할 수 있도록 공유합니다. MATLAB MCP Server Toolbox가 설치되어 이 함수를 사용할 수 있는 상태여야 합니다.

            

              
MATLAB Toolkit만 사용: startup.m에 추가

              
% Share this MATLAB session with the MATLAB MCP Server
shareMATLABSession()

            


            
B. Simulink 또는 MATLAB·Simulink Toolkit을 함께 사용하는 경우

            
Simulink Toolkit의 설치 경로를 추가한 뒤 satk_initialize를 실행합니다. 이 함수는 도구 경로를 설정하고 내부에서 shareMATLABSession을 호출합니다. 두 Toolkit을 함께 설치해도 A의 코드를 중복 추가할 필요가 없습니다.

            

              
Simulink 또는 두 Toolkit 사용: startup.m에 추가

              
% Initialize Simulink tools and share this MATLAB session
if ispc
    addpath(fullfile(getenv('USERPROFILE'), '.matlab', 'agentic-toolkits', 'simulink'))
else
    addpath("~/.matlab/agentic-toolkits/simulink")
end
satk_initialize

            

            
위 경로는 설치 후 Toolkit 경로입니다. 반입 폴더인 D:\agentic-offline과 구분하며, 다른 위치에 설치했다면 실제 설치 경로로 수정합니다. 이 예시는 특정 릴리스 조건을 두지 않았으며, Simulink Toolkit은 MATLAB R2023a 이상과 Simulink가 필요합니다.


            
공식 근거: MATLAB Toolkit — 기존 MATLAB 세션 공유 · Simulink Toolkit — MATLAB Setup / startup.m · MATLAB startup 문서
공식 저장소 확인일: 2026-11-05

AI Agent 설정

          
이 섹션은 Roo Code를 예시 Agent로 사용하여 설명합니다. 동일한 개념은 Codex, Copilot, Claude Code 등 다른 MCP 지원 Agent에도 적용할 수 있습니다.

        

        

          예시 구성 개념: Roo Code는 예시 Agent이며 LLM 자체가 아닙니다. 개인 PC의 Roo Code가 사내 API endpoint를 통해 Gemma 또는 Qwen 계열 내부 LLM에 요청을 보내고, 별도의 MCP 연결을 통해 로컬 MATLAB/Simulink 작업을 실행합니다. 외부 인터넷은 필요하지 않지만 개인 PC에서 내부 LLM endpoint로의 사내망 통신은 허용되어야 합니다.
        

        
중요: Roo Code는 본 문서의 설명을 위한 예시 Agent입니다. 고객 환경에서는 Codex, GitHub Copilot, Claude Code, Gemini CLI 또는 MCP를 지원하는 다른 Agent를 사용할 수 있습니다. 핵심 원리는 "Agent → 내부 LLM → MATLAB MCP Server → MATLAB/Simulink" 연결 구조입니다.

          
1. 내부 LLM
Gemma4 31B, Qwen3.6 등 사내 모델을 OpenAI-compatible API 또는 Roo Code가 지원하는 provider 방식으로 제공합니다.

          
2. Roo Code
사용자 목표를 해석하고 작업 순서를 계획합니다. Base URL, API Key, Model ID는 고객의 내부 LLM gateway 값으로 설정합니다.

          
3. MATLAB MCP
Roo Code의 tool call을 MATLAB session에 전달합니다. Simulink extension file을 함께 지정해야 Simulink 전용 tool이 노출됩니다.

        

        

          
폐쇄망 Agentic AI 연결 구조

          
개인 PC의 VS Code + Roo Code
        │
        ├── HTTPS/REST ──> 사내 LLM API Gateway
        │                  └── Gemma4 31B / Qwen3.6
        │
        └── local MCP ──> MATLAB MCP Server
                           └── MATLAB + Simulink Agentic Toolkit

MATLAB MCP Server 등록

          

        

        

          --matlab-session-mode=existing: 실행 중이며 공유된 MATLAB 세션에 연결합니다.

          --extension-file: Simulink 전용 MCP 도구를 불러올 tools.json의 경로를 지정합니다.
        

        

          <user> 값: MCP 설정 JSON의 <user>는 사용자 PC의 계정 이름 또는 실제 설치 경로에 맞게 변경해야 합니다.

          두 연결을 구분하십시오.

          ① Roo Code → 내부 LLM API: 추론과 계획을 위한 연결입니다.

          ② Roo Code → MATLAB MCP Server: MATLAB/Simulink 실행을 위한 로컬 도구 연결입니다.

          API Key는 LLM gateway 인증에 사용되며 MATLAB MCP Server 실행 경로를 대신하지 않습니다.
